# valetkey design direction

Owner's answers, transcribed. Applies to every page valetkey serves
(sign-in, home, connect, tokens, activity, consent).

## Personality

Warm and friendly. A person who does not work in ops should understand every
page: plain words, short sentences, no jargon where a common word exists.

## Theme

Follows the operating system (`prefers-color-scheme`) with a toggle to switch.
Light and dark must both work fully.

## Palette

- Accent: amber (yellow-orange). Used sparingly.
- Neutrals for everything else.

## Typography

- System font stack for all text; no external fonts.
- Monospace only for data that is code: tool names, arguments, tokens, URLs,
  scope JSON.

## Dials

Dial: ENERGY 2 / RHYTHM 1 / MOTION 1
