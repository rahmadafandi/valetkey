Add valetkey to your AI client

Add this address as a remote MCP server. The first time, your client asks you to sign in here.

{{.MCPURL}}

Claude Code: run

claude mcp add --transport http valetkey {{.MCPURL}}

Claude Desktop or claude.ai: open Settings, then Connectors, choose Add custom connector and paste the address.

Cursor: add this to ~/.cursor/mcp.json

{"mcpServers": {"valetkey": {"url": "{{.MCPURL}}"}}}

Any other client that speaks MCP with OAuth works the same way: give it the address above.
